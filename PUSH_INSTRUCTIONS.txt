GitHub may require a Personal Access Token instead of password.

To create a token:

1. Go to: https://github.com/settings/tokens

2. Click "Generate new token" → "Generate new token (classic)"

3. Fill in:
   • Note: "Job Aggregator Deploy"
   • Expiration: 90 days (or your choice)
   • Select scopes: Check "repo" (this gives all repo permissions)

4. Click "Generate token"

5. COPY THE TOKEN (you won't see it again!)

6. Use the token as password when pushing:
   Username: dayyalabhanuprakash
   Password: [paste your token]
